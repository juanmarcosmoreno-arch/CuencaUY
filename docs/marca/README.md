# CuencaUY — marca

**CuencaUY · La lechería uruguaya en el mapa**

El símbolo une un marcador de mapa y una gota de leche: la lechería ubicada en el territorio. Funciona desde 16 px.

| Archivo | Uso |
|---|---|
| `cuencauy-horizontal.svg` / `.png` | Logo principal sobre fondos claros |
| `cuencauy-horizontal-oscuro.svg` / `.png` | Sobre fondos oscuros |
| `cuencauy-palabra.svg` / `.png` | Solo el nombre, para espacios chicos |
| `cuencauy-simbolo.svg`, `-1024.png` | Símbolo solo |
| `cuencauy-simbolo-oscuro.svg` | Símbolo sobre fondo oscuro |
| `cuencauy-app-icono.svg`, `-512.png`, `apple-touch-icon.png`, `favicon-32.png` | Ícono de app, perfil de redes y favicon |

El texto está convertido a trazados (tipografía Inter, SIL OFL), así que los SVG no dependen de fuentes instaladas. Margen de respeto: la altura de la «C» alrededor del logo.
